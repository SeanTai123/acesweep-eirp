# Hardware

The proposed chassis uses three encoder-equipped omni wheels in a Kiwi drive arrangement. An acrylic deck supports the battery and a removable mesh hopper. The intake uses a guarded foam roller, a curved ramp and a through-beam sensor at the hopper entrance.

CAD models, STL files, the KiCad carrier design and the bill of materials will be added as the hardware is developed. The first bench checks will establish roller clearance, motor current and power supply requirements.
